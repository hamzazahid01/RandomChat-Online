💬 RandomChat-Online
 
A real-time chat application built with Node.js, Express, Socket.IO, and MongoDB.
Supports rooms, authentication, emojis, voice messages, image sharing, reactions, replies, and more.

🚀 Features:
      🔐 User Registration & Login (Session-based auth)
      🏠 Multiple Chat Rooms
      💬 Real-time Messaging (Socket.IO)
      😊 Emoji Support
      🎤 Voice Messages (Press & Hold)
      ❌ Unsend Messages
      🛠 Admin Panel (Create/Delete/Reorder Rooms)
      📱 Responsive Modern UI
      🛠 Tech Stack

Backend

Node.js

Express.js

Socket.IO

MongoDB (Mongoose)

Express-Session

Multer (File Uploads)

Bcrypt (Password Hashing)

Frontend

EJS Templates

Vanilla JavaScript

Custom CSS (Modern Chat UI)
